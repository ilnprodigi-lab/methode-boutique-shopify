Pour bien démarrer

Le dropshipping, et c'est quoi DSers ?

Le dropshipping, c'est vendre un produit sans l'avoir en stock : le fournisseur l'expédie directement à ton client. Une appli fait le lien entre ta boutique et le fournisseur.

  1. Le client commandeIl paie ton prix de vente sur ta boutique Shopify.
  2. L'appli transmetElle prépare la commande chez le fournisseur, avec l'adresse du client.
  3. Tu paies le fournisseurTu règles le prix d'achat, en général en un clic.
  4. Le fournisseur expédieLe colis part directement chez le client.
  5. Le suivi remonteLe numéro de suivi arrive dans Shopify, qui l'envoie au client par e-mail.
Marge = prix de vente − prix fournisseur − livraison payée − frais de paiement − publicité

Fiche : DSers en 5 points

DSers est une appli Shopify, partenaire officiel d'AliExpress. Elle a un plan gratuit pour démarrer. C'est celle qu'on a utilisée pour AironiMenager.

À surveiller : l'entrepôt d'expédition (Europe ou Asie change tout le délai), le stock du fournisseur qui peut tomber à zéro, et le paiement rapide des commandes pour ne pas retarder l'envoi.

Modèle

La boutique hybride

Une boutique hybride mélange plusieurs façons de vendre au lieu de tout miser sur une seule. Le mot recouvre trois cas.

Stock + dropshipping

Les produits qui se vendent bien sont achetés en petite quantité et stockés (livraison rapide, contrôle qualité, emballage à ta marque). Le reste reste en dropshipping pour tester sans risque.

Fournisseurs Europe + Asie

Les appareils viennent d'entrepôts européens (5 à 10 jours), les accessoires d'Asie (10 à 20 jours). Chaque fiche affiche son vrai délai.

En ligne + physique

La même boutique Shopify vend sur le site et en vrai (marché, salon, magasin) avec Shopify POS : un seul stock, un seul fichier clients.

Choix de départ

Shopify ou WooCommerce ? Et les paiements

Shopify est un service tout-en-un qu'on loue. WooCommerce est une extension gratuite de WordPress qu'on installe et qu'on entretient soi-même. Le bon choix dépend surtout du temps que tu veux passer sur la technique.

Versements bloqués : ce qu'on entend souvent

Au début, Shopify peut retenir l'argent le temps de vérifier l'identité, ou imposer un délai de 30 jours dans certains secteurs. Ce n'est pas propre à Shopify : Stripe, PayPal et Whop font pareil dès qu'ils voient du risque (boutique récente, délais longs, litiges). Ce qui l'évite : délais annoncés et tenus, numéros de suivi, pages légales complètes, peu de litiges.

Pour AironiMenager

Shopify Payments + PayPal, et éventuellement le paiement en 3 ou 4 fois (Alma) pour les appareils chers. Passer sur WooCommerce aurait obligé à tout refaire pour quelques dizaines d'euros d'économie par mois.

Avant tout

Les règles d'or

Les CGV font foi

Chaque délai, prix de livraison, durée de retour ou moyen de paiement écrit sur le site doit être identique aux CGV et aux réglages Shopify.

Que des chiffres fabricant

Jamais d'estimation. Si on ne sait pas : « Non communiquée ». Toujours signaler « annoncé par le fabricant ».

Aucune promesse sans preuve

Pas de best-seller, de prix barré, de « nouveau prix », d'allégation santé ou de SAV fabricant sans données réelles.

Un produit = ce qu'il est

Ne jamais présenter un modèle pour un autre. Une vidéo d'un modèle proche se signale comme telle.

Tester ordinateur et mobile

Chaque changement est vérifié en ligne, sur grand écran et en largeur téléphone (390 px).

Garder une trace

Un journal des modifications et une sauvegarde avant chaque changement de masse (produits, photos, variantes).

Statut et marché

À faire avant de vendre quoi que ce soit : sans statut, la vente en ligne régulière est illégale et Google refuse les pages légales incomplètes.

Étape 2

Marque

Une identité simple et cohérente, décidée une fois pour toutes, avant de toucher au thème.

Étape 3

Choix des produits

Peu de produits, bien choisis, dont on connaît l'origine et le délai.

Étape 4

Fiches produits

C'est là que Google contrôle le plus. Chaque phrase doit pouvoir être prouvée par la fiche ou les visuels du fabricant.

Interdit sur une fiche

Estimations présentées comme des faits, « élimine 99,99 % des bactéries », « SAV 24 mois » non prouvé, « le meilleur rapport qualité-prix » sans calcul, durée de vie promise, superlatif faux à l'échelle du catalogue.

Pour la technique

Pièges techniques déjà rencontrés

Chacun nous a coûté du temps une fois. Les connaître évite de les refaire.

Thème

Envoyer une section avant le gabarit qui utilise ses nouveaux réglages, sinon Shopify les efface. Comparer la version en ligne avant d'écraser un gabarit (l'éditeur a pu le modifier).

Handles

Les sections stockent l'adresse (handle) du produit. Renommer une URL vide la section : la corriger dans le gabarit.

Éditeur de texte riche

Les titres modifiables n'acceptent pas class="" : passer par <em> et le styler en CSS. Les ombres de Dawn avancent par pas de 5 %.

Politiques

Les pages /policies/ ignorent le gabarit de page : les styler via .shopify-policy__*.

Panier

Dawn remplace le HTML du panier à chaque changement : un script placé dedans ne se relance pas. Tout mettre dans un fichier JS global (délégation d'événements). Une réduction ciblée sur des produits se lit dans cart.discount_applications, ligne par ligne.

Métachamps et API

L'espace de noms doit faire 3 caractères minimum. L'API ne peut pas publier un produit sur les canaux : passer par l'import CSV. Le mode privé (mot de passe) se coupe à la main dans l'admin.

Appli fournisseur

Sur DSers, le mapping avancé est obligatoire dès deux options. Dans toutes les applis, vérifier après chaque enregistrement que le lien variante ↔ fournisseur a bien été pris.

Photos partagées

Une même image peut servir à plusieurs produits : la retirer d'un produit ne la retire pas des autres. Sauvegarder avant de supprimer.

Sécurité

Ne jamais donner un mot de passe, une carte bancaire ou une clé API dans la conversation. Claude ne se connecte pas à ta place, ne paie rien et ne supprime rien sans ton accord explicite. Donner à chaque outil le minimum de droits.

Bonnes pratiques

Travailler sur une copie du thème avant de publier, sauvegarder avant une modification en masse, relire ce qui part en ligne, garder un journal des changements. Une demande précise (« vérifie que mes fiches disent la même chose que mes CGV ») donne un meilleur résultat qu'une demande vague.

À garder sous la main

Lexique

Les mots qu'on entend partout en e-commerce, en marketing et côté technique, expliqués simplement.

E-commerce

Dropshipping
Vente sans stock : le fournisseur expédie directement au client.
Boutique hybride
Boutique qui mélange plusieurs façons de vendre : stock à soi et dropshipping, ou en ligne et en magasin (voir la partie dédiée).
Fournisseur
Celui qui fabrique ou stocke le produit et l'expédie : vendeur AliExpress, grossiste européen…
Niche
Le petit marché précis que vise la boutique (ex. aspirateurs et entretien de la maison).
D2C / DTC
« Direct to consumer » : une marque qui vend directement au client, sans magasin intermédiaire.
B2C / B2B
Vente aux particuliers (B2C) ou aux entreprises (B2B).
WooCommerce
Extension gratuite qui transforme un site WordPress en boutique. Hébergement, mises à jour et sécurité sont à ta charge.
Passerelle de paiement
Le service qui encaisse la carte du client pour toi : Shopify Payments, Stripe, PayPal…
Versement (payout)
Le moment où l'argent encaissé arrive sur ton compte bancaire. En France avec Shopify Payments : 3 jours.
Réserve / fonds retenus
Une partie de l'argent gardée quelque temps par la passerelle de paiement pour couvrir d'éventuels litiges ou remboursements.
Marketplace
Site qui vend les produits de nombreux vendeurs : Amazon, Cdiscount, AliExpress.
Print on demand
Produit imprimé seulement après la commande (t-shirt, mug), sans stock.
Variante / SKU
Une version d'un produit (couleur, taille, lot) et son code unique.
Mapping
Lien entre une variante de ta boutique et la variante du fournisseur.
CA
Chiffre d'affaires : total des ventes encaissées, avant de retirer les coûts.
Marge
Ce qu'il reste après avoir payé le produit, la livraison, les frais de paiement et la pub.
Panier moyen (AOV)
Montant moyen d'une commande : CA ÷ nombre de commandes.
Taux de conversion (CR)
Part des visites qui finissent en commande : commandes ÷ visites × 100. 1 à 3 % est un ordre de grandeur courant.
Panier abandonné
Client qui a rempli son panier sans payer. Un e-mail de relance en récupère une partie.
Upsell / cross-sell
Proposer une version supérieure (upsell) ou un produit complémentaire (cross-sell), comme les filtres avec le robot.
Valeur vie client (LTV)
Ce qu'un client rapporte sur toutes ses commandes, pas seulement la première.
Fulfillment
Tout ce qui se passe après l'achat : préparation, emballage, expédition.
Prix barré
Ancien prix affiché à côté du prix actuel. Légal seulement s'il a vraiment été pratiqué (plus bas prix des 30 derniers jours).
CGV
Conditions générales de vente : le contrat entre toi et le client. Tout le site doit dire la même chose.
Rétractation
Les 14 jours pendant lesquels un client en ligne peut changer d'avis sans se justifier.

Marketing et publicité

SEO
Référencement naturel : apparaître gratuitement dans Google grâce au contenu, aux titres, à la vitesse du site et aux liens qui pointent vers lui. Lent mais durable.
SEA
Référencement payant : les annonces Google Ads au-dessus des résultats. Rapide, mais s'arrête quand on arrête de payer.
SEM
Le tout : SEO + SEA.
Social ads
Publicités sur les réseaux sociaux (Facebook, Instagram, TikTok).
Mot-clé
Ce que les gens tapent dans Google (« aspirateur balai sans fil puissant »).
Balise title / meta description
Le titre et le petit texte qui s'affichent dans les résultats Google. Ils donnent envie de cliquer.
Backlink
Un lien d'un autre site vers le tien. Google y voit un signe de confiance.
Données structurées
Informations cachées dans la page (prix, avis, contact) que Google lit pour enrichir ses résultats.
Merchant Center
L'outil de Google où arrivent tes produits pour Google Shopping. Il vérifie que rien n'est trompeur.
KPI
Indicateur clé qu'on suit pour savoir si ça marche : CR, panier moyen, ROAS…
CTR
Taux de clic : clics ÷ affichages × 100.
CPC / CPM
Coût par clic / coût pour mille affichages d'une publicité.
ROAS
Retour sur dépense publicitaire : CA généré ÷ budget pub. Un ROAS de 3 = 3 € de ventes pour 1 € de pub.
ROI
Retour sur investissement : ce que tu gagnes vraiment, une fois tous les coûts retirés.
CAC
Coût d'acquisition client : ce que coûte en pub l'arrivée d'un nouveau client.
Tunnel de vente
Le chemin du client : il découvre, s'intéresse, ajoute au panier, paie. On cherche où il décroche.
Landing page
Page d'arrivée pensée pour une seule action, souvent liée à une publicité.
CTA
Appel à l'action : le bouton ou la phrase qui dit quoi faire (« Ajouter au panier »).
Pixel
Petit code de suivi (Meta, Google, TikTok) qui mesure ce que font les visiteurs venus d'une pub.
Retargeting
Montrer une pub aux personnes déjà venues sur le site sans acheter.
A/B test
Comparer deux versions (titre, photo, prix) sur deux groupes de visiteurs pour garder la meilleure.
Taux de rebond
Part des visiteurs qui repartent après une seule page.
UGC
Contenu créé par des clients (photos, vidéos). À utiliser seulement avec leur accord écrit.
Preuve sociale
Ce qui rassure par les autres : avis, notes, photos de clients.
Persona
Portrait type du client visé : âge, besoins, budget, freins.
Opt-in
Accord explicite du client pour recevoir des e-mails marketing (obligatoire avec le RGPD).

Technique : Shopify, web et IA

HTML / CSS / JavaScript
Le trio du web : la structure de la page, son apparence, ses comportements (un bouton qui ajoute au panier).
Liquid
Le langage de modèles de Shopify : du HTML avec des trous que Shopify remplit (nom du produit, prix…).
Thème, section, bloc
Le thème est l'apparence complète ; une section est une bande de page ; un bloc est un élément dans une section.
Dawn
Le thème gratuit de Shopify, une bonne base à personnaliser.
Métachamp
Champ personnalisé ajouté à un produit (ex. autonomie) pour l'afficher sur la fiche.
API
Porte d'entrée qui permet à un programme de lire ou modifier la boutique (produits, prix, commandes) sans passer par l'écran.
GraphQL
Le format des requêtes de l'API Admin de Shopify : on demande exactement les champs voulus.
CLI
Outil qui s'utilise en tapant des commandes. La Shopify CLI envoie un thème ou interroge l'API.
Scopes (droits)
Ce qu'une appli ou un outil a le droit de faire : lire les produits, les modifier, lire les commandes…
Token / clé API
Le mot de passe d'un programme. Ne jamais le coller dans une conversation ni le publier.
Webhook
Message envoyé automatiquement par Shopify quand quelque chose arrive (nouvelle commande).
MCP
Model Context Protocol : standard ouvert qui branche une IA comme Claude sur des outils et services (des « connecteurs »).
Claude Code
Claude qui travaille sur ton ordinateur : il lit et modifie des fichiers, lance des commandes et peut piloter un navigateur.
Git / GitHub
Git garde l'historique des versions d'un projet ; GitHub l'héberge en ligne.
Vercel
Hébergeur qui met un site en ligne à partir d'un dépôt GitHub, et le met à jour à chaque modification.
Domaine / DNS
Le nom du site (maboutique.com) et le réglage qui le relie au bon serveur.
CDN
Réseau de serveurs qui livre images et fichiers depuis l'endroit le plus proche du visiteur.
